# Gigly — Creator Gig Marketplace

A marketplace where young creators monetize their skills and clients book them.

**Hackathon ID:** [AZIS-VNBMAJ]

## Track
Creator Economy — Creator Gig Marketplace

## Tech Stack
- Vanilla HTML + CSS + JavaScript (no build step required)
- localStorage for data persistence
- Single-file deployment (index.html)

## Run Steps
1. Clone or download this repository
2. Open `index.html` in any modern browser
3. That's it — no installation, no server, no account needed

## Features Implemented
1. **Post a Gig** — Creators list services with title, category, rate, description
2. **Browse & Search** — Marketplace with search, category filters, and sorting
3. **Book a Gig** — Clients book via modal form with confirmation screen
4. **Creator Dashboard** — Creators see incoming bookings and accept/decline
5. **My Bookings** — Clients track booking status (Pending/Accepted/Declined)

## Standard API
**No** — This project uses a browser-based UI, not a standard API. Grading should be done via browser agent driving the UI.
